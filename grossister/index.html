Branscher

IT och system för grossister och partihandel

B2B-kunder beställer själva, med sina egna priser.

Grossister tar emot order via telefon, mejl och Excel, med olika priser per kund. När kunderna i stället beställer i en egen portal med sina avtalspriser försvinner mycket manuell inmatning.

Vanliga utmaningar

  • Order kommer via mejl och telefon
  • Kundunika priser hanteras för hand
  • Lagersaldo är osäkert vid beställning

Det här kan byggas

  • B2B-portal med kundpriser och orderhistorik
  • Order direkt till lager och ekonomi
  • Lager- och inköpsplanering
  • Integrationer med kunders och leverantörers system

Relevant erfarenhet

  • Leverantörsportal för 500+ leverantörer (ITG, Turkiet)
  • Inköp och lager i ett ERP-system (Samsara Solutions, Bulgarien)

Vanliga frågor

Kan varje kund ha sina egna priser?

Ja. Avtalspriser, rabatter och sortiment kan styras per kund.

Fungerar det med vårt affärssystem?

Portalen kopplas till ert affärssystem via API eller filer.

Fler områden

  • Butiker och detaljhandel

    Kassa, lager och webbutik med samma saldo.

  • E-handel

    Webbutik, betalningar och leveranser som hänger ihop.

  • Bilhandlare och verkstäder

    Verkstadsbokning, påminnelser om service och lager av delar.

  • Hotell, vandrarhem och B&B

    Direktbokning, rum och gästkommunikation.

  • Restauranger och kaféer

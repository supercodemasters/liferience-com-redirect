Branscher

IT och system för butiker

Butik, lager och webb som visar samma sak.

Fysiska butiker som också säljer på nätet behöver samma saldo, priser och kunder i båda kanalerna. Annars säljs varor som inte finns, och kampanjer måste läggas in två gånger.

Vanliga utmaningar

  • Saldon skiljer mellan kassa och webbutik
  • Kampanjer läggs in på flera ställen
  • Svårt att se vad som säljer

Det här kan byggas

  • Synk av lager och priser mellan kassa och webbutik
  • Klick och hämta i butiken
  • Kundklubb och erbjudanden
  • Dashboard för försäljning per butik och produkt

Relevant erfarenhet

  • Smyckesbutik i Magento med enstegskassa och presentkort (59 Souls, USA)

Vanliga frågor

Måste vi byta kassasystem?

Nej, om kassan har ett API eller kan exportera data.

Kan kunden se om varan finns i butiken?

Ja. Butikssaldot kan visas på produktsidan.
